## Türkçe

Sürüm araçları gerçek depoda v1.2.1 → v1.2.2 artışı ve yalnızca güncel CHANGELOG bölümünün TR/EN çıkarımıyla doğrulandı. Testler; sayısal SemVer karşılaştırmasını, geçersiz/eksik notlarda dosyaların değişmemesini, dry-run davranışını, yanlış commit'teki etiketin reddini, yayımlanmış sürümün korunmasını, taslağın tamamlanmasını, bozuk ZIP/eksik dosya reddini ve GitHub erişim hatalarında yayın yapılmamasını kapsar. Google imzası olumsuz testinde rastgele imzanın son karakterlerini değiştirmek yerine bir bayt kesin olarak değiştirilir; test artık nadiren geçerli imza üretmez. GitHub Release yayını, aynı koşunun test ve Docker işleri tamamlandıktan sonra çalışır; sonuç Actions bağlantısından ayrıca görülebilir. [Sürüm rehberi](RELEASING.md).

Google giriş akışı canlı anahtar veya gerçek Google parolası kullanılmadan, yalnızca test sunucusunda bulunan imzalı taklit sağlayıcıyla doğrulandı. İlk girişte geçerli eski sunucu misafir köyü hesaba bağlanır; başka cihazda ve süreç yeniden başlatılınca aynı ilerleme açılır. Yeni misafir oturumu oluşturulmaz; eski misafir çerezi `/api/session`, `/api/state` ve `/api/action` için oyun erişimi sağlamaz. Çıkış sırasında geciken bir yanıt köyü yeniden açamaz. Geçersiz API yanıtı yerel oyuna düşmez. Eski tarayıcı kayıtları değiştirilmez ve yeni yerel oyun kaydı yazılmaz.

Ana sayfa masaüstü, tablet, mobil ve koyu temada incelendi. Mobilde görselin tamamı metnin altında görünür. Sayfa sonundaki tekrar giriş kaldırıldı; görünür alt bilgilerde kişi adı yoktur. Analiz, oturum çözülürken geçici bir ana sayfa ziyareti saymaz ve oturumsuz köy bağlantısını yalnızca `/home` olarak ölçer. Analiz payload'larına hesap e-postası, oyun durumu veya çerez eklenmez.

Gerçek Google girişini açmak için [Google Cloud ve Dokploy ayarları](GOOGLE-SIGNIN.md) gerekir. Anahtarlar yerelde boş olduğundan Google düğmesi kapalıdır ve oyun erişimi yoktur. Kalıcı oyun ve analiz volume'ları korundu.

Yerel kontroller GitHub CI sonucuyla aynı değildir; bu commit'in [GitHub Actions koşusu](https://github.com/emindemirciai/Bozkurt-Obasi/actions/workflows/web-ci.yml) ayrıca kontrol edilmelidir.

## English

Release tooling was verified with the actual v1.2.1 → v1.2.2 bump and extraction of only the current CHANGELOG section in both languages. Tests cover numeric SemVer ordering, unchanged files after invalid/missing notes, dry-run behavior, rejecting tags at another commit, preserving published releases, completing drafts, rejecting corrupt ZIPs/missing assets, and stopping on GitHub access failures. The negative Google signature test now flips a byte deterministically instead of replacing trailing characters that could occasionally remain unchanged. Publishing runs after tests and Docker jobs in the same workflow; inspect the Actions link for the remote result. See the [release guide](RELEASING.md).

OAuth was verified without live credentials or real Google passwords using a signed mock provider that exists only in the test server. First sign-in can claim a valid earlier server guest village; progress resumes on another device and after restart. Signature, audience, nonce, state, cookie, replay and same-origin negative tests passed. New guest sessions are not created; an old guest cookie cannot access `/api/session`, `/api/state` or `/api/action`. A delayed response after logout cannot reopen the village, and invalid API responses never fall back to local gameplay. Earlier browser saves remain untouched; no new local game save is written.

The homepage was reviewed on desktop, tablet, mobile and in dark mode. The complete artwork fits the desktop screen height at its native 1672:941 ratio; TR/EN dimensions match and Google sign-in stays on the first screen at 1280×720, 1366×768, 1905×910 and 1920×1080. Mobile displays the full image below the copy. The duplicate bottom sign-in was removed and visible footers omit the personal name. The GitHub About description, website and six topics were verified by readback. The standalone `preview/index.html` embeds the artwork and Google icon for homepage/theme/language preview; it cannot open the game without a server Google session. Analytics waits for authentication to resolve instead of recording a transient homepage visit, and an unauthenticated village link records only `/home`. Payloads omit account email, game state and cookies.

Live sign-in needs the [Google Cloud and Dokploy configuration](GOOGLE-SIGNIN.md). Local credentials are empty, so the Google button and game access are closed. Local stack smoke skipped authenticated admin/analytics panel login because `ADMIN_PASSWORD` is unset; admin authentication passed unit tests. Persistent game and analytics volumes were preserved.

The earlier 27 September VPS check returned 503 `admin_unavailable` for the admin session and 502 for `admin.bozkurtobasi.com/healthz`. This release does not confirm a VPS deployment: verify Dokploy `ADMIN_PASSWORD`/`ADMIN_EMAIL` and the `admin:3000` domain mapping, then redeploy. Local verification is separate from GitHub CI; inspect this commit's [GitHub Actions run](https://github.com/emindemirciai/Bozkurt-Obasi/actions/workflows/web-ci.yml).
