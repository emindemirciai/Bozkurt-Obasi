# Release WP-05

## Eklenenler

- Altı farklı çakal rolü
- Rol bazlı sağlık, hasar, hız, saldırı sıklığı, hedefleme ve görünüş profilleri
- Çakal sürüsü koordinatörü
- Beş aşamalı otomatik taktik döngüsü
- Sol, sağ ve çift kanat hazırlık noktaları
- Sürüye toplu hücum hedef önceliği
- Uluma ile alan etkili geçici çakal güçlendirmesi
- Çakal lideri ve lider kaybında koordinasyon bozulması
- HUD taktik ve lider göstergeleri
- Manuel taktik değiştirme test düğmesi
- Rol profilleri için Edit Mode testleri

## Güncelleme notu

Mevcut projenin üzerine kopyalandığında `ProjectSettings/BozkurtWp05Setup.complete` işaretçisi olmadığı için sahneler WP-05 düzenine göre otomatik yeniden oluşturulur. Otomatik işlem çalışmazsa `Bozkurt > Project > Run Current Setup (WP-05)` komutu kullanılabilir.
