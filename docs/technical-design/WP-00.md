# WP-00 — Proje Temeli

## Amaç

Unity istemcisini sonraki iş paketlerinin üzerine güvenle kurulabileceği modüler bir yapıda başlatmak.

## Teslim edilen bileşenler

1. Unity 6000.3.17f1 proje sürümü
2. URP 17.3.0
3. Input System 1.19.0
4. Unity Test Framework 1.4.6
5. Servis kayıt sistemi
6. Bootstrap sahne akışı
7. Atomik JSON kayıt sistemi
8. İzometrik kamera
9. Ters-hilal ve yıldız formasyon üreticileri
10. Otomatik Editor kurulum aracı
11. Edit Mode testleri

## Sahne akışı

`00_Bootstrap` → `01_MainMenu` → `02_FormationPrototype`

## Mimari sınırlar

- Oyun verileri ile sahne bileşenleri ayrılacak.
- Ağ bağlantısı WP-11'e kadar zorunlu olmayacak.
- Tek oyunculu döngü internet olmadan çalışacak.
- Unity sahne nesneleri servis mantığını doğrudan sahiplenmeyecek.
- Formasyon algoritmaları Unity sahnesinden bağımsız test edilebilir kalacak.
