# WP-02 Teslim Notu

Paket, WP-00 ve WP-01 üzerine ilk çalışan savaş döngüsünü ekler.

## Sürüm

- Unity Editor: 6000.3.17f1
- Paket: WP-00 + WP-01 + WP-02
- Önceki düzeltme: HOTFIX-01 Input System assembly referansı korunmuştur.

## Kurulum sonrası beklenen görünüm

- Çakallar kurtlara doğru ilerler.
- Kurtlar yakındaki çakalları otomatik hedefler ve saldırır.
- Her iki tarafın sağlık çubuğu görünür.
- Canı biten kurt koyu renge dönerek bayılır.
- Aktif bir kurt seçilip baygın kurda sağ tıklanırsa kurtarma başlar.
- Savaş sıfırlanabilir ve kurtlar debug düğmesiyle iyileştirilebilir.
