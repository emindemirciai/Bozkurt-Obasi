# WP-08 Teslim Notu

Bu sürüm WP-00–WP-07 üzerine kamp ve ana yurt sistemini ekler.

## Test akışı

1. Ana Yurt yakınında Kamp menüsünü açın.
2. Yapı Seç ile yapı türünü değiştirin.
3. Yapıyı Kur ile seçili yapıyı yerleştirin.
4. Savaşta kurtları ve sürüyü yaralayın.
5. Savaş bittikten sonra Kampta Dinlen komutunu kullanın.
6. Başka rota noktasına göç edin.
7. Ana Yurttan uzaktayken Kamp Kur komutuyla geçici kamp oluşturun.
8. Erzak Deposu kurup kaynak kapasitesinin arttığını doğrulayın.
