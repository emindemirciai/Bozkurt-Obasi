# Release WP-07

## Güncelleme kurulumu

1. Unity'yi kapatın.
2. WP-07 UPDATE arşivini çıkartın.
3. `bozkurt-obasi` klasörünü mevcut projenin üzerine kopyalayın.
4. Dosyaları değiştirme seçeneğini onaylayın.
5. Aynı `client` klasörünü Unity Hub ile açın.
6. Gerekirse `Bozkurt > Project > Run Current Setup (WP-07)` komutunu çalıştırın.

Yeni `ProjectSettings/BozkurtWp07Setup.complete` işaretçisi WP-07 sahnelerinin bir kez otomatik oluşturulmasını sağlar.
