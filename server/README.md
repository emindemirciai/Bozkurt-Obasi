# Server

WP-11, Nakama'nın yerleşik hesap, arkadaşlık ve Storage Engine özelliklerini özel runtime kodu olmadan kullanır.

Özel TypeScript RPC'leri; kullanıcı arama, sohbet moderasyonu, doğrulanmış görev ödülleri ve gerçek zamanlı ortak görevler eklenirken bu klasöre eklenecektir. Yerel Nakama/PostgreSQL kurulumu `infrastructure/nakama` klasöründedir.
